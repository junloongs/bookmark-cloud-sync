# 商店截图占位说明

请按以下 5 张规格制作并保存到本目录。文件名必须保留带前缀编号，方便商店排序。

## 通用规格

- **尺寸**：1280×800 像素（首选）或 640×400 像素
- **格式**：PNG（24-bit，不带 alpha 或带 alpha 都可）
- **最大文件大小**：Edge 10MB，Chrome 10MB
- **数量**：Edge 需要 1-10 张，建议 5 张；Chrome 建议 5 张
- **内容要求**：无真实账号密码 / 无真实邮箱 / 无私人书签

## 5 张截图清单

### 📸 01-settings.png — 设置页（已连接状态）

**展示内容**：扩展设置页右上角显示「✔ 连接成功」的提示，账号密码已填（用占位字符如 `••••••••` 即可）。

**文案建议**（截图右下角文字标注）：

**文案建议**：
> 「错误提示不再是『Something went wrong』，而是中文引导你自查。」

## 设计风格

- 背景：浅色（#F3F4F6 或 #FFFFFF）
- 主色调：靛蓝紫罗兰（#6366F1 / #8B5CF6）
- 字体：系统默认或思源黑体（macOS 用苹方、Windows 用微软雅黑）
- 截图下加一行小字（24-32px 高）说明功能亮点

## 推荐工具

- **Figma**：先做模板，按编号导出
- **Snipping Tool**（Windows）或 **Cmd+Shift+4**（macOS）截图后用 **Figma / Affinity** 加标注
- **Shottr**（macOS）：一键截图加边框和阴影

## 隐私注意

- ❌ 不要用真实账号 / 真实 WebDAV URL（除非你愿意展示自己的坚果云域名截图，否则用 `https://dav.example.com/dav/` 占位）
- ❌ 不要展示真实书签内容（用占位字符串如「示例书签」）
- ❌ 不要展示真实邮箱 / 真实密码
