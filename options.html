浏览器兼容性

Chrome / Edge 上扩展可正常工作。夸克、360 极速 X、QQ 浏览器等基于 Chromium 的国产浏览器 通常会内置「网盘助手 / 密码管理」功能，对坚果云（dav.jianguoyun.com）做自动登录探测—— 表现就是浏览器自己弹一个 WebDAV 账号密码框，过几秒探测完成就自动消失。
这是浏览器内置行为，与本扩展无关（扩展在 Edge / Chrome 上同样的代码不会触发）。 关闭方法：
  • 夸克浏览器（最容易触发）：≡ → 设置 → 通用 → 密码管理箱 → 关闭「密码保存提示」；再返回设置 → 隐私与安全 → 关闭「自动填充」
  • 360 极速 X：右上角菜单 → 设置 → 高级设置 → 内置功能 → 关闭「网盘小工具」
  • QQ 浏览器：菜单 → 设置 → 高级 → 关闭「网盘助手」/「第三方账号自动登录」
如果关闭后扩展同步失败，请把诊断面板输出截给开发者。
密码仅保存在本机浏览器扩展存储中，只会直接发送给你所配置的 WebDAV 服务器， 不会上传到任何第三方。请勿在公共电脑上保存账号密码。
