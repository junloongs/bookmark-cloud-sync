# 隐私政策（Privacy Policy）

最后更新：2026-10-13

## 概述

「书签云同步」（Bookmark Cloud Sync）是一款浏览器扩展，**完全在你的设备和由你指定的 WebDAV 服务器之间运行**。本扩展由独立开发者维护，**不运营任何服务器**，**不收集任何遥测数据**。

## 我们收集什么

**我们不收集任何东西。**

具体地，本扩展不会：
- ❌ 收集任何使用统计
- ❌ 上传你的书签内容到任何第三方服务器（只到你配置的 WebDAV 服务器）
- ❌ 上传你的 WebDAV 账号密码到任何地方（密码只存在你本机浏览器的扩展存储里）
- ❌ 跟踪你的浏览行为
- ❌ 与任何第三方共享数据
- ❌ 嵌入广告、分析脚本、远程脚本

## 数据流向

```
你的浏览器 ──Basic Auth──► 你配置的 WebDAV 服务器
   ▲                                │
   └─────── 同步的书签 JSON ◄───────┘
                ▲
                │ （本扩展只在这条路径上工作）
                │
        无第三方参与
```

你的数据路径**只有两条端点**：
1. **你的浏览器**（通过本扩展）
2. **你配置的 WebDAV 服务器**（完全由你控制）

本扩展**从不**把数据发到其他地方。

## 数据存储位置

本扩展只在以下位置存储数据，**全部在你本机**：

| 数据类型 | 存储位置 | 加密 |
|---|---|---|
| 你的配置（WebDAV 地址 / 用户名 / 应用密码） | `chrome.storage.local`（浏览器扩展专用存储） | 浏览器自动（Chrome/Edge 在用户系统盘加密存储） |
| 同步状态（节点 GUID 映射、时间戳缓存） | 同上 | 同上 |
| 设备标识（用于多端合并时区分来源） | 同上 | 同上 |

## 权限说明

| 权限 | 用途 |
|---|---|
| `bookmarks` | 读取 / 修改你浏览器中的书签（合并/上传/下载必备） |
| `storage` | 在你浏览器本机保存配置与同步状态 |
| `alarms` | 实现定时自动同步 |
| `unlimitedStorage` | 支持同步大量书签（>5 MB） |
| `optional_host_permissions` (动态申请) | 访问你指定的 WebDAV 服务器域名 |

本扩展**不使用**：
- ❌ 任何 `tabs` / `webNavigation` / `activeTab` 权限
- ❌ 任何 `<all_urls>` 通配 host permission
- ❌ 任何远程脚本（`content_security_policy` 默认 `script-src 'self'`）
- ❌ 任何 `webRequest` / `declarativeNetRequest`（不读取/修改其它网站请求）

## 第三方服务

本扩展**不调用任何第三方服务**，包括但不限于：
- 不调用任何分析服务（无 Google Analytics、无 Sentry）
- 不调用任何 CDN（所有资源在扩展包内）
- 不调用任何远程代码加载

唯一的网络请求目标**就是你配置的 WebDAV 服务器**。

## 儿童隐私

本扩展不针对 13 岁以下儿童设计，且不会有意收集儿童数据。
